# CLAUDE.md — правила репозитория

- Задача и решения: `docs/PLAN.md`. Решения меняются только с обоснованием там же.
- Стек: Node.js LTS + TypeScript strict, zod на всё внешнее (SERP, LLM, Sheets), тесты vitest.
- Слои: `src/interfaces` → `src/core` → интерфейсы (`Store`, `SerpProvider`, `Fetcher`, `Labeler`) ← `src/adapters`. Ядро не импортирует адаптеры напрямую.
- Sheets: колонки читаются по имени заголовка. Одно чтение на лист, пакетная запись в конце этапа, никакой построчной записи, строки не удаляются.
- Проект личный: только личные аккаунты и ключи, никаких корпоративных. `ANTHROPIC_API_KEY` — с личного аккаунта.
- Секреты только в `.env` (в git не попадает). JSON сервисного аккаунта лежит вне репозитория. Ключи не печатаются в логи и чат.
- SERP-квота бесплатная и маленькая (100 запросов): разработка на фикстурах и `--from-cache`. Реальный прогон только с «ок» Евгения.
- Действия наружу (создание репозитория, push, платные прогоны сверх согласованных) — только после явного «ок».
- Цифры (стоимость, точность, счётчики) берутся из листа `Runs`, кода и `docs/LABEL_CHECK.md`, а не из оценок.
- Промпт классификатора: `prompts/classify.md`, версия в шапке. При правке поднимать версию.
- Перед сдачей вехи: `npm test` зелёный, отчёт 5–10 строк, затем ждать «ок».
