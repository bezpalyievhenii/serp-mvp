# Сценарий видео (≤ 5 минут)

**Подготовка до записи.**
- Открыты: таблица Google Sheets, терминал в `serp-mvp/`, браузер на `http://localhost:3000` (`npm run serve`), `docs/LABEL_CHECK.md`.
- Для блока «повтор без дублей» нужен уже сделанный сегодня прогон: тогда повтор возьмёт сегодняшний снимок и пройдёт за секунды. Если запись в другой день, сделайте утром `npm run run` (~2 мин, ~12 запросов SearchApi).
- Для истории позиций лучше записывать на второй день: тогда в `History` будут две даты и стрелки изменений.
- Размер шрифта в терминале и браузере — крупный. Окна заранее разложены.

**Если что-то пошло не так во время записи:** нет интернета или квоты → показать `npm run serve -- --demo` (демо-данные, жёлтая плашка). Ошибка доступа → `npm run doctor` сам говорит, что исправить: это тоже стоит показать.
