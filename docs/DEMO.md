# Сценарий видео (≤ 5 минут)

Видео показывает **приложение**. Google-таблица появляется один раз на 10 секунд как хранилище.

**Подготовка до записи.**
- `npm run serve` → браузер на `http://localhost:3000`. Если порт занят, запустите `PORT=3005 npm run serve` и откройте `:3005`.
- Терминал в `serp-mvp/` рядом с браузером.
- Блок «Повтор без дублей» лучше записывать в день, когда уже был прогон: повтор возьмёт сегодняшний снимок и пройдёт за секунды. Если прогона сегодня ещё не было, первый «Запустить сейчас» займёт ~2 минуты и ~12 запросов SearchApi. Вырежьте ожидание при монтаже.
- Стрелки изменений в «Истории позиций» появятся, если записывать на второй день после прогона.
- Автозапуск в «Расписании» выключен, его включение показываем только в кадре.
- Крупный шрифт, окна разложены заранее.
